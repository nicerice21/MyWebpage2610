# デザイン仕様書

## デザインコンセプト

```text
Paper Portfolio
余白のある紙面に、手書きの注釈と技術記録が並ぶ
```

派手なアニメーションや画像主体ではなく、白い紙・黒い文字・罫線・小さな注釈で構成します。

## ビジュアル設計

### カラーパレット

```text
Background: #F7F4EE
Paper:      #FFFDF8
Text:       #252525
Muted:      #77736B
Line:       #D9D3C8
Accent:     #C85C45
Link:       #315D73
```

- 背景は完全な白ではなく、薄い生成り色
- 本文は黒に近い濃色
- アクセントカラーは1色だけ
- グラデーションや過度な装飾は使わない

### タイポグラフィ

本文は読みやすさを優先し、見出しだけ少し個性を出します。

```text
日本語本文:
Noto Sans JP またはシステムフォント

英数字・見出し:
Inter / IBM Plex Mono / JetBrains Mono
```

Google Fontsを大量に読み込むより、システムフォントを基本にすると軽量です。

```css
font-family:
  "Hiragino Kaku Gothic ProN",
  "Yu Gothic",
  system-ui,
  sans-serif;
```

コードや技術名だけ等幅フォントにします。

## レイアウト

### 基本構造

```text
┌─────────────────────────────┐
│ 名前                 MENU   │
├─────────────────────────────┤
│                             │
│  Student Engineer           │
│  作ることで、考える。        │
│                             │
├─────────────────────────────┤
│ About                       │
│ ─────────────────────────── │
│ Projects                    │
│ ─────────────────────────── │
│ Articles                    │
│ ─────────────────────────── │
│ Contact                     │
└─────────────────────────────┘
```

- 最大幅：960〜1100px
- 左右余白：スマートフォン16〜24px、PC48px以上
- セクション間に大きな余白
- カードを並べすぎず、紙面のように縦へ流す
- 罫線で情報を区切る

## Heroのデザイン

Heroは大きな写真やイラストを使わず、テキスト主体にします。

```text
PORTFOLIO / 2026

Student Engineer
〇〇大学で情報技術を学びながら、
Webアプリケーションを開発しています。

[Projectsを見る]  [GitHub]
```

右側または下部に、手書き風の小さなメモを配置します。

```text
↳ interested in
  web / cloud / design
```

手書きフォントを使う場合も、1〜2箇所の注釈だけに限定します。本文全体を手書き風にすると読みにくくなります。

## プロジェクト一覧

プロジェクトはカードよりも「紙面上の記録」に近づけます。

```text
01  Task Management App
    チームのタスク管理を効率化するWebアプリ

    Astro / Hono / Cloudflare R2
                                      View project →
────────────────────────────────────
02  ...
```

各項目に以下を表示します。

- 番号
- プロジェクト名
- 一言概要
- 技術スタック
- 開発年
- 詳細ページへのリンク

画像は一覧では小さく、詳細ページで大きく表示します。これによりトップページの読み込みを軽くできます。

## プロジェクト詳細ページ

詳細ページは「開発ノート」風にします。

```text
PROJECT 01

Task Management App
チーム開発のためのタスク管理アプリ

─────────────────────────────

Overview

Background

Tech Stack
  Astro
  Hono
  Cloudflare Workers
  Cloudflare R2

Challenges
```

プロジェクト画像には、次のような紙面表現を加えます。

- 薄い罫線
- 画像のキャプション
- 図番号
- `Fig. 01`のようなラベル
- 小さな注釈
- 画像の周囲に十分な余白

ただし、実際の画像ファイルに影や紙テクスチャを焼き込むより、CSSで表現した方が軽量です。

## 紙っぽさの出し方

紙の質感を画像で再現しすぎると重くなるため、基本はCSSで作ります。

```css
.paper {
  background: #fffdf8;
  border: 1px solid #d9d3c8;
  box-shadow: 3px 3px 0 rgba(40, 35, 25, 0.08);
}

.note {
  color: #77736b;
  font-family: ui-monospace, monospace;
  font-size: 0.8rem;
}
```

紙っぽさは次の要素だけで十分です。

- 生成り色の背景
- 細い罫線
- 少しずれた影
- 番号やキャプション
- 注釈
- 大きな余白

紙テクスチャ画像、常時動く背景、複雑なSVGフィルターは避けます。

## アニメーション

軽量性を優先し、アニメーションは最小限にします。

使うなら次の程度です。

- リンクの下線が伸びる
- ページ表示時に文字が少しだけ現れる
- プロジェクト画像が数px移動する
- ホバー時に罫線の色が変わる

```css
a {
  text-decoration: underline;
  text-underline-offset: 0.25em;
  transition: color 160ms ease;
}

a:hover {
  color: #c85c45;
}
```

`prefers-reduced-motion`にも対応します。

## 軽量化の方針

- Astroの静的生成を使う
- JavaScriptは必要な箇所だけ
- トップページの画像は遅延読み込み
- 画像はWebPまたはAVIF
- R2には圧縮済み画像を保存
- Webフォントを使いすぎない
- UIライブラリを使わない
- 大きな背景画像を使わない
- 記事APIはWorker側でキャッシュ
- アイコンは文字・CSS・小さなSVGで表現

## 推奨デザイン仕様

```text
コンセプト: 紙の開発ノート
背景:       生成り色
本文:       黒に近い濃色
アクセント: 赤茶色または青灰色
最大幅:     1040px
角丸:       ほぼ使わない
影:         3px程度の控えめな影
罫線:       1px
アニメーション: 160〜240ms程度
画像:       R2 + WebP/AVIF
```

最終的には「紙の質感を再現するサイト」ではなく、「紙面の編集デザインをWebに移したサイト」と考えると、軽量で洗練された見た目になります。
